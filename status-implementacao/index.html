    Resumo¶

    • Pronto (✅): o loop interativo de ponta a ponta — ideia/issue (incl. motor escaneando o repo) → proposta→ok → implementação → PR → review → gate humano; Telegram + cockpit PWA (trilha O, fatias 1–7: chat vivo, refino + aplicar na issue, terminal real do motor em tmux) + motores + auditoria de token + outbox/idempotência/recuperação.
    • Parcial (🟡): second brain (só lê), observabilidade/secrets/orçamento, tenancy (1 por processo), roteamento fino de modelo.
    • Falta (❌): control-plane multi-empresa, skills, gatilhos de ambiente, evals/sandbox forte, merge-queue/test-impact, versão de prompt por run, Spec Kit, agente sênior/acesso a dados da empresa.
